# Reena Devi: sample reel (test #1, piles / बवासीर)

Files
- reena-devi-piles-sample.mp4: 1080x1920, about 79 s, Hindi VO, burned-in captions, AI label + medical disclaimer
- reena-devi-piles-sample.srt: caption file (for YouTube/Meta upload)
- script.json: the script, line by line, with on-screen cards
- build.py: rebuilds the whole video from script.json (edit a line, re-run)

Rebuild: needs piper-tts, numpy, Pillow (raqm), ffmpeg, fonts-noto-core, and the Hindi Piper voice
hi_IN-priyamvada-medium (sherpa-onnx GitHub release "tts-models"). Set RD_VOICE to the .onnx path.

Limits of this test build
- Voice model licence is CC BY-NC-SA 4.0 (non-commercial). Fine for an internal test, NOT for a monetised channel.
- Character is 2D illustrated with amplitude lip-sync, not a photoreal avatar.
